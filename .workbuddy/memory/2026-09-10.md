## 黑屏排查与修复（关键踩坑）
- 症状：127.0.0.1:4173 整页全黑、无任何内容；构建通过、服务端 200、资源 hash 全部对得上
- 根因：项目**没有装 @vitejs/plugin-react**，Vite 走 esbuild 默认「经典 JSX 转换」，要求每个 JSX 文件都 `import React`。重构拆出的组件都没写这行 → 运行时 `ReferenceError: React is not defined`，`#root` 为空只剩黑底。**构建期完全不报错**，只能靠浏览器控制台抓
- 修复：`vite.config.js` 加 `esbuild: { jsx: "automatic" }`，组件无需再 import React
- 排查工具链（可复用）：agent-browser 的 Chromium 下载会超时失败；改用 `playwright-core`（装到 `C:\Users\Administrator\.workbuddy\binaries\node\workspace`，npm --prefix）+ `executablePath` 指向系统 Edge（`C:\Program Files (x86)\Microsoft\Edge\Application\msedge.exe`）无头渲染，可抓 console/pageerror/requestfailed + 截图。注意项目 `package.json` 是 `"type": "module"`，检查脚本必须用 `.cjs` 后缀
- 顺手修复：Google Fonts 的 `<link rel="stylesheet">` 是渲染阻塞资源，墙内环境可能卡首屏，已改成 `media="print" onload="this.media='all'"` 非阻塞模式 + preload；并加了内联 SVG favicon 消掉 /favicon.ico 404
- 最终验证：无头渲染 rootChildren=1、8 个 section、hero 选中 webp、控制台 0 报错；桌面 1440 与移动 390 截图均正常
- 环境备注：PowerShell 的 Remove-Item 被 safe-delete 钩子接管转入回收站，可能报 "trash-failed/aborted" 但文件实际已删，以 `Get-ChildItem -Force` 复核为准
