## 本地联调踩的两个真 bug（已修，都是实跑才暴露的）

   - 修法：`netlify/lib/guard.mjs` 加 `toResponse(r)`；4 个 function 改为

## 第四个 bug（最严重）：Netlify ESM Functions 传的是 Request，不是 v1 event（已修）
- 症状：`GET /api/auth` 返回 `405 {"message":"不支持 undefined"}` —— `event.httpMethod` 是 undefined
- 原因：Netlify ESM functions 走 **v2 签名**（`export default async (req: Request, context)`），
  只有 `req.method` / `req.url`，**没有** `httpMethod` / `queryStringParameters` / `body` 字段
- 后果：所有分支判断都落空，**登录直接 405，后台根本进不去**
- 修法：`netlify/lib/guard.mjs` 加 `netlifyHandler(fn)` 适配器，把 Request 转成 v1 event
  （同时兼容本来就是 v1 event 的调用，所以冒烟测试不用改）；4 个 function 改为 `export default netlifyHandler(handler)`
- 实测修复后：`/api/auth` → `200 {"authenticated":false}`，`/api/content` 未登录 → `401 UNAUTHORIZED`
- **教训**：本地冒烟只测 handler（传 v1 event），完全测不到运行时的签名差异。以后 Netlify functions 必须实跑一次端到端
- 注：netlify dev 会 watch functions 目录热重载，改完不用手动重启（实测改动 6 秒内生效）
