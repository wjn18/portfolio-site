## 推送中断：GitHub TLS 握手失败（间歇性出口故障）
- 症状：`git push` 报 `schannel: failed to receive handshake, SSL/TLS connection failed`；换 `-c http.sslBackend=openssl` 则报 `unexpected eof while reading`；`git ls-remote` 也无输出
- 诊断：环境注入了 `HTTP_PROXY=http://127.0.0.1:61119`，端口 `OPEN`（node net 可连）但 CONNECT 到 github:443 被掐；node 直连 github 15s 超时 → **出口侧问题，不是凭据也不是 git 配置**
- 关键判断：同一环境 10 分钟前的 `3c23d17`、`bfcf400` 两次推送都成功 → 间歇性故障，别去改 remote / 凭据 / sslBackend，等或换网络即可
- 处理 → **结果：后台重试第 2 次即成功（故障约 2 分钟内自愈），`bfcf400..6803cbd` 已推送**。结论：遇到这个报错先间隔 25-30s 重试 2-3 次，不要去改 remote / 凭据 / sslBackend；只有在持续 10 分钟以上失败时才让用户在本地网络推
- 备注：本机没有 `origin/main` 远程跟踪 ref（`git rev-list origin/main..main` 报 unknown revision），查落后进度要用 `git log --oneline` 对比远端网页或用 `git ls-remote origin main`
